# Curso de Python, videoaula 05: Funções

> Repositório oficial das videoaulas do Curso de Python do canal Fabricio Curvello no YouTube.

## Sobre

Este é um dos **repositórios oficiais das videoaulas do Curso de Python** do canal [Fabricio Curvello no YouTube](https://www.youtube.com/@fabriciocurvello). O código é o mesmo apresentado nas aulas, para o aluno acompanhar, executar e modificar.

Assunto desta parte do curso: Criação e uso de funções, parâmetros, lambda e módulos.

## Arquivos

- `exemplo_funcao1.py` a `exemplo_funcao3.py`: definição de funções, parâmetros e retorno.
- `exemplo_funcao_multipos_parametros.py`: funções com vários parâmetros.
- `exemplo_funcao_lambda.py`: funções anônimas (`lambda`).
- `calculos.py` e `exemplo_calculos.py`: organização de funções em um módulo próprio e importação.

## Tecnologias

- **Python 3**
- **PyCharm** (IDE usada nas videoaulas)

## Como executar

Com o [Python 3](https://www.python.org/downloads/) instalado:

```bash
git clone https://github.com/fabcurvello/CursoPythonVideoaulas05funcoes.git
cd CursoPythonVideoaulas05funcoes
python main.py
```

Para rodar outro exemplo, troque `main.py` pelo nome do arquivo. Também é possível abrir a pasta no PyCharm e executar pelo botão ▶.
